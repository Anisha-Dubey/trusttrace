# Phase 06: Baseline Agency Authentic Editorial Visual Architecture & Curated Multi-View Trust Suite

## Executive Summary

Phase 06 establishes the definitive visual identity, layout architecture, and interactive multi-view experience for the TRUSTTRACE web platform. Drawing direct creative direction and architectural precision from **Baseline Agency** (`https://www.baseline.agency/`, Cluj-Napoca, led by Victor Deaconu) and synthesizing the component specifications from `nototpushongithub`, Phase 06 elevates TRUSTTRACE from a functional diagnostic tool into an editorial-grade security intelligence system.

Conventional cybersecurity scanners produce binary, reductive outputs—typically a simplistic green padlock or a red exclamation mark—that obscure critical epistemic uncertainty, conflate transport security with organizational legitimacy, and actively expose users to browser exploitation risks. TRUSTTRACE establishes an uncompromising counter-paradigm: **evidence-first, unbundled trust adjudication across 4 verifiable dimensions with audited provenance and deterministic abstention.**

## 1. Architectural Principles Derived from Baseline Agency

### 1.1 Editorial Tone & Manifesto Hierarchy
- **Primary Hero Manifesto**: *"You got here with your security signals working against you. Imagine them on your side. We rebuild the baseline of web trust."*
- **Positioning Statement**: *"Conventional security tools produce a binary green lock that hides critical uncertainty. TRUSTTRACE unbundles trust across 4 verifiable dimensions with audited evidence lineage and zero active browser exploitation surface."*
- **Typography Scale**: High-contrast, tight-tracking neo-grotesque sans (`Space Grotesk` / `Inter Tight`, `-0.04em` tracking, `0.95` leading) paired with monospaced technical indicators (`Space Mono` / `JetBrains Mono`) and classic editorial serif accents (`Averia Serif Libre` / `Syne`).

### 1.2 The Three-Step Baseline Methodology Bento
Directly mirrors the three-step narrative cadence from `https://www.baseline.agency/`:
1. **01 / IDENTIFY (We find what's actually misleading)**: Uncovers the dangerous disconnect between Domain Validation (DV) transport encryption and organizational authenticity. Identifies homoglyph lookalikes, expired certificates, and uncorroborated threat feed noise.
2. **02 / REBUILD (We rebuild it as one system)**: Reconstructs trust across four mathematically isolated dimensions: **The Transport**, **The Identity**, **The Behavior**, and **The Threat Intelligence**.
3. **03 / DELIVER (People get it before you explain it)**: Translates complex cryptographic observations and probabilistic risk models into undeniable, self-explanatory Evidence Passports with explicit abstention notices instead of false assurances.

### 1.3 Baseline High-Contrast Visual System
- **Void Deep Canvas**: `#080808` / `#0a0a0a` deep obsidian background with hairline micro-grid divisions (`rgba(255, 255, 255, 0.08)`).
- **Surface Elevation**: `#121212` elevated bento panels with corner technical registration marks (`// 01_TRIAGE_INTAKE`, `[RFC1918_PREFLIGHT]`, `[SEC_001]`).
- **Signal Volt Accent**: `#CCFF00` (Electric Acid Volt) used exclusively for active states, verified telemetry beacons, and high-priority action triggers.
- **Multidimensional State Palette**:
  - `CAUTION` / Danger: `#FF3366` (Crimson)
  - `SUSPICIOUS` / Warning: `#FFAA00` (Amber)
  - `INCONCLUSIVE` / Abstention: `#00F0FF` (Cyan Signal)
  - `NO THREAT OBSERVED` / Benchmark: `#CCFF00` (Volt)

## 2. Integrated Feature Modules

### 2.1 Top Technical Telemetry Strip & Navigation
- Real-time station ticker displaying active engine status, thesis statements, coverage invariants, and live connection to the FastAPI backend bridge (`/health`).
- Sticky frosted glass header (`backdrop-blur-md`) with brand lockup (`TRUSTTRACE / v1.0`), five tabbed module triggers (`[01] Triage Studio`, `[02] Gallery`, `[03] Evidence Passport`, `[04] Threat Intel`, `[05] 8 Invariants`), procedural audio synthesizer toggle, and instant JSON export.

### 2.2 Triage Studio & Controlled Demonstrations
- **Preflight Boundary Guard**: Real-time client-side and server-side validation against RFC1918 private subnets, loopback addresses (`127.0.0.1`, `localhost`), cloud metadata targets (`169.254.169.254`), embedded credential URIs (`user:pass@host`), and Cyrillic/IDN homoglyph lookalikes.
- **Animated Five-Stage Scan Sequence**:
  1. `SEC-001`: Intake Boundary Gate
  2. `TLS-001`: Cryptographic TLS Audit
  3. `TLS-DV`: RDAP Delegation Lineage
  4. `EVID-002`: Adversarial Threat Feeds
  5. `SAFE-001`: Policy Adjudication
- **Benchmark Scenario Selectors**: One-click execution of canonical test fixtures:
  - `phishing_lookalike`: `bank-secure-lоgin.com` (Valid DV TLS + Cyrillic homoglyph)
  - `legitimate`: `example.com` (Verified identity + clean telemetry)
  - `expired_tls`: `legacy-portal.internal-corp.net` (Hygiene lapse ≠ active attack)
  - `conflicting`: `disputed-target.org` (Discordant feeds → deterministic abstention)

### 2.3 Curated Case Gallery
- Editorial case study portfolio categorizing real-world trust failures across Phishing Lookalikes, Infrastructure Hygiene, Adversarial Intelligence, and Active Defense.
- Split-dimensional metric cards comparing transport status against true entity authenticity.

### 2.4 Evidence Passport & Provenance Engine
- **Verdict & Confidence Band**: Explicit mapping to Worker 03 confidence tiers (`VERIFIED_DEFENSE`, `ESTABLISHED_BASELINE`, `LIMITED_OBSERVATION`, `HIGH_CONFLICT`, `UNCHECKED`).
- **Explicit Abstention Notice Banner**: Rendered whenever coverage is partial or evidence is conflicting, detailing missing check categories and rescan guidance.
- **The 4 Verifiable Dimensions**:
  - `01 // IDENTITY`: Subject DN, Organization, SAN count, Domain Age, RDAP authority.
  - `02 // TRANSPORT`: Protocol TLS 1.3, Cipher suite, Validity window, Expiration status.
  - `03 // BEHAVIOR`: Redirect hops, Form action endpoints, Script sandboxing, HTTP status.
  - `04 // THREAT INTELLIGENCE`: OpenPhish, PhishTank, Community Reports, Sybil Corroboration.
- **Coverage Gauge**: Strict mathematical accounting: `Total = Observed + Failed + Not Run`.
- **Evidence Provenance Table**: Chronological audit trail showing Evidence ID, Collector Source, Timestamp, Reliability Tier, and Invariant Limitations.

### 2.5 Community Threat Intelligence Feed
- Interactive threat reporting interface enforcing anti-sybil protections, source family separation, reporter pseudonymization, and HTML/script sanitization.
- Live feed of community reports with status lifecycle transitions (`unverified` → `corroborated` / `disputed`).

### 2.6 The 8 Architectural Invariants Explorer
- Dedicated interactive module presenting all eight formal invariants with exact mathematical rules, rationale, and one-click benchmark verification buttons.

### 2.7 Baseline Editorial FAQ Section
- Direct adaptation of Baseline Agency's *"The things worth asking before you hire anyone"*, reframed as *"The things worth asking before you trust any web signal"*, addressing SSL misinterpretations, collector timeout handling, abstention policies, and SSRF containment.
