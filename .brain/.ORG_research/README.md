# Preserved source material

This directory contains selected original files copied from the uploaded `HackMatrix.zip`. Originals are preserved as supplied; they are not all equally reliable. For interpretation, read `../.research/research_synthesis.md` and `../.research/archive_quality_and_limits.md`. The later audit governs where it corrects older working documents.

`manifest.csv` records relative file name, source archive path, SHA-256, and role. The full original ZIP (including unrelated bulk papers and nested archives) was not duplicated into this workspace to keep the deliverable manageable; the uploader retains it.

See `source_link_map.md` for the two inherited machine-local links in the preserved audit source. The original source file content was not rewritten.
