## Freeze decisions
TRUSTTRACE remains the umbrella project. The hackathon MVP is one evidence-linked URL triage journey, not the full long-term research platform. Certificate validity is separate from organisational legitimacy. Missing evidence is not benign. No live arbitrary-site browser execution unless an isolated worker and SSRF controls are implemented and tested. The archive audit warns that generic CT/DNS/ML fusion has prior art; no novelty or accuracy claims are approved without comparative evidence.
